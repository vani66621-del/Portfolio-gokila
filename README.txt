FILES

HOW TO PREVIEW
1. Keep all files and the assets folder together.
2. Open index.html in a modern browser.
3. For a local server, run: python -m http.server 8000
   Then open http://localhost:8000

DESIGN DIRECTION
The redesign follows an “editorial clarity” concept: an uncluttered white canvas, confident typography, restrained lavender accents, rounded but light surfaces, generous spacing, and direct labels. The portrait is a square image clipped to a true circle at all breakpoints. The process section emphasizes the path from understanding the problem to validating the interface.
