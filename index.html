How I approach a problem

Clarity before pixels.

A practical, iterative approach that connects user needs, clear journeys, thoughtful interfaces, and implementation checks.

STEP 01 / 05

Start with people, not screens.

Explore user needs, the problem, and product context before making design decisions.

ResearchRequirementsCompetitor review
STEP 02 / 05

Give the problem a clear direction.

Clarify the problem and organize key user journeys so the design has a focused purpose.

Problem framingUser journeysPriorities
STEP 03 / 05

Make room for better possibilities.

Explore ideas, map user flows, and sketch wireframes to establish a clear structure.

IdeasUser flowsWireframes
STEP 04 / 05

Turn the structure into an experience.

Create consistent interfaces and interactive prototypes, paying attention to hierarchy, readability, and usability.

Visual designComponentsPrototypes
STEP 05 / 05

Check the details. Keep improving.

Review usability and test the implemented UI against approved designs. Document issues and refine the experience before launch.

Usability reviewUI test casesHandoff

An iterative process — feedback can take me back to any step.
